# Конвертер температур

React-приложение для конвертации температур между градусами Цельсия (°C) и Фаренгейта (°F).

## Функциональность

- Конвертация °C в °F и обратно
- Автоматический расчет при вводе
- История конвертаций
- Локальное сохранение данных

## Установка и запуск

```bash
npm install
npm start
