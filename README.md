# Конвертер температур

React-приложение для конвертации температур между градусами Цельсия (°C) и Фаренгейта (°F).


## 🚀 Функциональность

- **Двусторонняя конвертация** - автоматический перевод между °C и °F
- **История конвертаций** - сохранение последних 10 операций
- **Локальное хранилище** - история сохраняется между сессиями
- **Адаптивный дизайн** - корректное отображение на разных устройствах
- **Очистка данных** - кнопки для очистки полей ввода и истории

## 🛠 Технологии

- **React 18** - функциональные компоненты и хуки
- **Local Storage** - сохранение данных в браузере
- **CSS3** - современные стили и градиенты
- **HTML5** - семантическая разметка

## ⚡ Установка и запуск

### Предварительные требования
- Node.js (версия 14 или выше)
- npm

## ⚡ Запуск

```bash
npm install
npm start
